В каждой работе сравниваются начальная и настроенная модели sklearn и две версии собственной реализации. Для сравнения используются одни и те же тестовые выборки.

2. [Логистическая и линейная регрессии](02_regression.ipynb)

[Итоговое сравнение](06_comparison.ipynb)

## Датасеты

- Avila. Определение одного из 12 переписчиков рукописи XII века по 10 признакам текста. Использовано разбиение авторов датасета. Основная метрика macro-F1 учитывает все классы с одинаковым весом. [Stefano et al., 2018, UCI, CC BY 4.0](https://doi.org/10.24432/C5K02X)
- Wave Energy Converters, Tasmania. Оценка мощности фермы по координатам 16 преобразователей. Для работы взято 7200 конфигураций. Вход включает только координаты. Основная метрика MAE измеряется в МВт. [Neshat et al., 2018, UCI, CC BY 4.0](https://doi.org/10.24432/C5831S)

Параметры подбираются по трехкратной кросс-валидации на обучающих данных. В Avila фолды стратифицированы по классам. В Tasmania совпадающие после округления до 10 м конфигурации остаются в одной группе. Группы разделены между обучением, тестом и фолдами. Для воспроизводимости задан seed 40122.

## Результаты

Случайный лес показал лучший результат в обеих задачах. У настроенного леса sklearn macro-F1 0,98705 на Avila и MAE 0,04620 МВт на Tasmania. У собственной версии 0,98378 и 0,04633 МВт соответственно.

## Запуск

Команды для PowerShell. Запускайте из корня репозитория.

```powershell
py -3.13 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe run_notebooks.py
```

В Linux и macOS используйте `python3.13` для создания окружения и `.venv/bin/python` для остальных команд. Аргумент `3` запускает только ЛР 3. Аргумент `summary` обновляет итоговый ноутбук по сохраненным метрикам.

При первом запуске скачиваются два архива UCI общим размером около 59 МБ. Загрузчик проверяет SHA-256 и хранит архивы в `.cache/`. Первое обучение CART включает компиляцию Numba.

## Данные

- **Классификация — Avila.** По десяти признакам геометрии текста определяется один из двенадцати переписчиков латинской рукописи XII века. Модель может предварительно распределять оцифрованные фрагменты для палеографической проверки. Используется опубликованное разбиение авторов. Macro-F1 даёт каждому классу одинаковый вес. Дополнительно измеряются balanced accuracy и accuracy. [Stefano et al., 2018, UCI, CC BY 4.0](https://doi.org/10.24432/C5K02X)
- **Регрессия — Wave Energy Converters, Tasmania.** По 32 координатам 16 преобразователей оценивается суммарная мощность фермы. Приближённая модель может ускорить предварительный отбор планировок перед гидродинамической симуляцией. Из исходного файла берётся фиксированная подвыборка до 7200 уникальных конфигураций. MAE показывает среднюю абсолютную ошибку в МВт. RMSE сильнее штрафует большие ошибки, а R² сопоставляет модель с прогнозом среднего. [Neshat et al., 2018, UCI, CC BY 4.0](https://doi.org/10.24432/C5831S)

Обучающая часть Avila разбита на три стратифицированных фолда. В Tasmania раскладки конвертеров с одинаковыми координатами после округления до 10 м и учёта перестановок остаются в одной группе. Группы разделяются между train и holdout, а внутри train — между тремя фолдами. Мощности отдельных преобразователей исключены из входных признаков. Преобразования, которым нужны статистики выборки, обучаются внутри фолда. Во всех работах используется seed `40122`.

## Результаты

На отложенных выборках случайный лес показал лучшие результаты по обеим основным метрикам. Настроенный лес sklearn получил macro-F1 **0,98705** на Avila и MAE **0,04620 МВт** на Tasmania. У собственного леса — **0,98378** и **0,04633 МВт** соответственно. Значения остальных моделей и границы сравнения приведены в [итоговом ноутбуке](06_comparison.ipynb).

## Запуск

Запускайте команды из корня репозитория с Python 3.13.

```sh
python -m venv .venv
# Windows PowerShell: .\.venv\Scripts\Activate.ps1
# Linux / macOS: source .venv/bin/activate
python -m pip install -r requirements.txt
python run_notebooks.py
```

Вариант для одной работы — `python run_notebooks.py 3`. Для пересборки сводки по сохранённым метрикам — `python run_notebooks.py summary`. Ноутбуки также можно открыть в VS Code с расширением Jupyter, выбрав интерпретатор виртуального окружения.

При первом запуске загрузчик скачивает два архива UCI общим размером около 59 МБ и сверяет SHA-256. Сами данные хранятся локально в `.cache/`. Первое вычисление CART включает компиляцию функций Numba.

Собственные оцениватели находятся в [labkit/models.py](labkit/models.py). NumPy, SciPy и Numba используются для численных операций и ускорения. scikit-learn используется для библиотечных моделей, разбиений, препроцессинга и метрик. Таблицы с holdout-метриками находятся в [results/](results/). Сводный ноутбук читает их без переобучения моделей.
